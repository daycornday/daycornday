### Data Analyst

실험 설계, 인과추론, 마케팅 측정, 지표 설계를 다룹니다. "이 숫자로 무엇을 결정할 수 있나"에서 출발해, 결론과 그 결론의 한계를 같이 적는 분석을 지향합니다.

**포트폴리오 → [data-analysis-portfolio](https://github.com/daycornday/data-analysis-portfolio)**

| 갈래 | 다루는 질문 |
|---|---|
| 실험 | 몇 명, 며칠 돌려야 하나? 결과는 어떻게 읽나? (실험 플레이북) |
| 인과추론 | 무작위 배정 없이 효과를 구할 수 있나? (DID, PSM) |
| 문제 발견 | 어느 단계를 고쳐야 활성 유저가 가장 많이 느나? (마르코프, 세그먼트, 아하모먼트) |
| 마케팅 측정 | 기여와 증분은 무엇이 다른가? (홀드아웃, 지역 실험, MMM) |
| 데이터 신뢰 | 같은 지표를 누가 뽑아도 같은 숫자가 나오나? (지표 마트, 검증 키트) |
